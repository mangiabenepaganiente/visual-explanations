Why tuning a guitar changes pitch

Turning a tuning peg changes the string’s tension. Tension sets how fast a wave runs along the string: v = √(T/μ), where μ is the mass per metre. The string only rings at waves that fit exactly between its two fixed ends. So the note is f = v / 2L = (1/2L)·√(T/μ). Tighter means faster waves, which means a higher note — not a louder one.

Try thisDrag tension until the tuner reads E4 ±0 cents, then press Pluck. Notice it takes about 70 N, roughly the weight of a 7 kg bag, just for the thinnest string.

Cause 01

Tension sets the wave speed

A kink on a string travels at v = √(T/μ). Pull harder (bigger T) and the string snaps back faster. A heavier string (bigger μ) is sluggish. Quadruple the tension and the speed, and so the pitch, doubles.

Cause 02

Only waves that fit survive

Both ends are pinned, so the string rings in standing waves that fit a whole number of half-wavelengths: λn = 2L/n. The lowest (fundamental) is f = v/2L. The overtones 2f, 3f, 4f… ring too and colour the tone.

Cause 03

Frets shorten L by 21/12

Pressing fret n leaves a vibrating length of L / 2n/12, so each fret raises the pitch one equal-tempered semitone. Fret 12 halves the length and doubles the frequency, which is one octave up.

Myth, busted

“Tighter = louder” · “the body makes the note”

Loudness is how far the string swings (amplitude). Pitch is how often it swings (frequency). Pluck harder and the note stays put. The guitar body is an amplifier and tone filter: it changes how the harmonics are balanced, not which frequencies the string makes. Try the body and strength controls — the tuner doesn’t budge.

Model, constants, caveats

  1. Ideal string (Mersenne’s laws / Taylor). Wave speed v = √(T/μ), fundamental f₁ = v/(2L), harmonics fₙ = n·f₁. It assumes a perfectly flexible string with rigid ends and small amplitude. Real steel strings have a little bending stiffness, so high overtones run slightly sharp (inharmonicity), and very hard plucks stretch the string and raise the pitch by a few cents. Neither effect is modeled.
  2. Linear density μ. Plain steel: μ = ρ·πd²/4 with ρ = 7850 kg/m³. A .010″ (0.254 mm) string gives μ ≈ 3.98×10⁻⁴ kg/m. The presets use unit weights for a D’Addario EXL110 (10–46) set, back-calculated from D’Addario’s published tension chart: .010 plain 3.96×10⁻⁴, .013 plain 6.70×10⁻⁴, .017 plain 1.15×10⁻³, .026 wound 2.26×10⁻³, .036 wound 4.17×10⁻³, .046 wound 6.61×10⁻³ kg/m. Wound strings are heavier than their core but not solid steel of the outer diameter, so their μ is not ρπd²/4.
  3. Check. E4 = 329.63 Hz on a 648 mm (25.5″) scale with μ = 3.98×10⁻⁴ kg/m needs T = μ(2Lf)² ≈ 72.6 N ≈ 16.3 lbf, matching D’Addario’s chart (16.22 lb for PL010). Source: D’Addario EXL110 tension chart at 25.5″, standard tuning: 16.22 / 15.39 / 16.58 / 18.38 / 19.04 / 16.91 lb (E4→E2), total 102.52 lb as printed on the pack; see D’Addario: What is guitar string tension? for the formula T = UW·(2LF)²/386.4. The six presets tuned to E2–E4 reproduce the chart within 0.1%, about 46.5 kg-force for the whole set.
  4. Notes and cents. Twelve-tone equal temperament with A4 = 440 Hz: n = 69 + 12·log₂(f/440) (MIDI number), nearest note = round(n), and cents = 100·(n − round(n)). Frets use the ideal rule Ln = L/2n/12. Real guitars add compensation at the saddle because fretting stretches the string slightly.
  5. The sound. A short additive synthesis, only after you click: harmonic n has amplitude ∝ |sin(nπβ)|/n² for a pluck at fraction β of the length (the ideal plucked-string spectrum). Higher harmonics decay faster, and there is a simple per-body tone weighting. It is a sketch of a guitar, not a recording. Clicking the string plucks at that spot, and plucking near the bridge sounds brighter.
  6. Slowed animation. The drawn string moves hundreds of times slower than the real one (a 330 Hz string completes 330 cycles per second). Higher notes are drawn visibly faster, and the harmonic mix matches the pluck point.
  7. For teachers. Waves and their properties: frequency, wavelength, speed (NGSS MS-PS4-1, HS-PS4-1). Try the classic check: fret 12 = octave, and 4× tension = octave. Name the misconceptions: “tighter strings are louder” and “the pitch comes from the body.”
